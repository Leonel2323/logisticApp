## secrity rules
- Ne jamais exposer les informations sensibles dans le code source.
- Ne pas stocker les mots de passe en clair, utiliser un algorithme de hachage sécurisé (ex: bcrypt).
- Ne pas exposer les clés API ou les secrets dans le code source ou dans les dépôts publics.
- Ne jamais faire confiance aux contrôles du frontend seuls.
